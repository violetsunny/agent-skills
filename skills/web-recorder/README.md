# 网页录制 🤖

**录制一次，永久自动化。**

网页录制是一个 [OpenClaw](https://github.com/openclaw/openclaw) 技能，可以将任何手动网页操作流程转换为可复用的自动化脚本——由 AI 驱动。

## 要解决的问题

知识工作者每周花大量时间在企业应用中重复网页操作：

- 📑 **报销单** — 填写相同的表单字段、上传发票、提交审批
- 📊 **数据提取** — 打开仪表盘、导出 CSV、复制粘贴到表格
- ✈️ **差旅申请** — 输入日期、目的地、项目代码、等待审批流程
- 💰 **付款申请** — 匹配发票和采购订单、填写金额、走审批流程
- 📋 **状态更新** — 从一个系统拉数据、汇总到另一个系统

这些任务每次都是同样的模式，但被登录墙、SSO 门户、复杂的多步骤 UI 挡住，传统自动化很难搞定。

## 解决方案

网页录制采用 **录制+回放** 的方式，结合 AI 增强：

1. **你做一遍** — 在真实浏览器中登录、点击、填写、提交
2. **AI 分析** — 捕获网络流量，分类每个字段
3. **生成脚本** — 参数化输入，可复用
4. **下次运行** — 直接跑脚本，或让 AI 助手帮你执行

```
 你（做一次）                    AI（以后每次）
┌──────────────┐              ┌──────────────────────────┐
│ 打开浏览器   │              │ $ npx ts-node run-api.ts │
│ 登录 SSO     │   ──────►   │   --amount 2500          │
│ 填写表单     │   录制       │   --date 2026-03-15      │
│ 点击提交     │              │   --reason "Q1出差"       │
└──────────────┘              └──────────────────────────┘
     15 分钟                         3 秒
```

## 核心功能

### 🔐 通用登录支持
支持任意认证方式——SSO（OIDC、SAML、CAS）、OAuth、用户名密码表单、多步骤登录（Google、Microsoft、Okta），或有验证码/2FA 的手动登录。Session 持久化并自动刷新。

### 🧠 AI 驱动的字段分析
自动将每个 API 字段分类为：
- **FIXED** — 每次都一样（审批流 ID、公司代码）→ 硬编码
- **DYNAMIC** — 每次运行不同（金额、日期、原因）→ CLI 参数
- **SESSION** — 认证 token/cookie → 自动管理
- **RELATIONAL** — 需要先查询（根据项目名称获取项目 ID）→ 自动解析

### 📊 两种任务类型

**查询/导出** — 从企业应用提取数据到结构化格式（JSON、CSV）。适合构建报表、仪表盘、跨系统汇总。

**提交** — 自动化表单提交，参数化输入。支持 `--dry-run` 模式预览请求，支持字段确认确保分类正确。

### 🔄 自修复测试循环
生成的脚本最多经过 5 轮自动化测试。当出现问题（session 过期、字段名变更、URL 错误），AI 自动诊断并修复。

### 📥 下载类型自动识别 (v6.5)
录制时自动检测文件下载操作，智能识别下载方式：
- **直接下载** — API 直接返回文件流
- **异步任务** — 提交任务 → 轮询状态 → 下载文件
- **Blob URL** — 前端生成文件后触发下载
- **iframe 下载** — 隐藏 iframe 触发下载

根据识别结果自动生成对应的下载处理代码。

### 🔧 注册为工具
任务测试通过后，注册为 OpenClaw 工具。AI 助手可以直接调用——"提交我的报销单"变成一句自然语言命令。

## 工作流程（7 阶段）

```
阶段一：🎬 录制       在浏览器中操作一次（支持任意登录方式）
阶段二：❓ 追问       AI 追问业务逻辑（默认参数、循环逻辑、输出路径等）
阶段三：🔍 分析       AI 分析网络流量 + 用户笔记，输出技术元数据 + 业务逻辑理解
阶段四：✅ 确认       先确认业务理解，再看技术细节（提交任务必须）
阶段五：📝 生成       生成双脚本（run-api.ts + run-ui.ts）+ 可靠性评估报告
阶段六：🧪 测试       迭代测试，自动修复（最多 5 轮）
阶段七：🔧 注册       注册为 OpenClaw 工具，可直接调用
```

## 快速开始

### 前置条件

- 已安装并配置 [OpenClaw](https://github.com/openclaw/openclaw)
- Node.js v18+
- Playwright（`npx playwright install chromium`）

### 1. 录制操作流程

```bash
# 从登录页开始
npx ts-node scripts/record.ts --name "报销单提交" --sso-url "https://sso.company.com"

# 或直接打开应用（无需登录）
npx ts-node scripts/record.ts --name "销售报表导出" --app-url "https://crm.company.com/reports"
```

浏览器窗口打开，按正常流程操作。完成后在终端输入 `done` 或在对话框告诉 AI "录完了"。

### 2. AI 分析 & 生成

OpenClaw AI 读取捕获的网络流量，识别核心 API，分类字段，生成参数化脚本。

对于**提交**任务，生成脚本前会要求确认字段分类。

### 3. 运行

```bash
# 查询任务 — 直接运行
npx ts-node ~/.openclaw/rpa/tasks/销售报表导出/run-api.ts --year 2026

# 提交任务 — 先预览，再提交
npx ts-node ~/.openclaw/rpa/tasks/报销单提交/run-api.ts --dry-run --amount 2500 --date 2026-03-15
npx ts-node ~/.openclaw/rpa/tasks/报销单提交/run-api.ts --amount 2500 --date 2026-03-15 --reason "客户拜访"
```

## 实际案例

| 任务 | 类型 | 自动化内容 |
|------|------|-----------|
| 拉取销售合同 | 查询 | 登录 CRM → 导航到合同页 → 提取所有记录 → 输出 JSON/CSV |
| 提交差旅申请 | 提交 | 登录报销系统 → 填写差旅表单 → 上传附件 → 提交审批 |
| 生成月度报表 | 查询 | 登录 BI 仪表盘 → 查询指标 → 导出结构化数据 |
| 处理付款申请 | 提交 | 读取发票 PDF → 填写付款表单 → 匹配采购订单 → 走审批流程 |
| 提取服务项目 | 查询 | 登录项目管理 → 按日期筛选 → 导出项目列表 |

## 架构

```
~/.openclaw/rpa/
├── tasks/<任务名>/               # 生成的自动化脚本
│   ├── run-api.ts                # API 模式脚本（含 session 检测 + 调 UI 登录）
│   ├── run-ui.ts                 # UI 模式脚本（Playwright 浏览器自动化）
│   ├── task-meta.json            # 任务配置（登录流程、字段映射、用法）
│   ├── field-mapping.json        # 字段名 → 中文标签
│   ├── recording.json            # 录制数据（网络流量 + 浏览器操作）
│   └── reliability-report.md     # 可靠性评估报告
├── sessions/<域名>.json          # 持久化登录 session（cookie/token）
└── credentials.enc               # 加密凭据（AES-256-GCM）
```

## 安全

- **凭据加密存储**（AES-256-GCM）— 永不明文
- **录制数据脱敏** — 分析后密码替换为 `[REDACTED]`
- **Session 和凭据不会提交** 到版本控制
- **生成的脚本不含硬编码密码**
- **文件权限受限**（敏感文件 0600）

## 技术栈

- **[Playwright](https://playwright.dev/)** — 浏览器自动化和网络拦截
- **TypeScript** — 生成的脚本完全类型化
- **OpenClaw** — AI 编排、工具注册、自然语言调用
