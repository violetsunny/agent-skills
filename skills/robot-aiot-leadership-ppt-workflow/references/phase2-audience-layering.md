# Phase 2: 受众分层

将内容拆成两份独立文档，服务不同受众，但共用同一数据池。

## 两份文档

1. 技术明细版：流程、泳道、异常处理、代码级引用
2. 领导汇报版：分层架构、能力总结、管理结论、数据支撑表

## 执行顺序

1. 先写技术明细版，确保对系统全貌理解完整
2. 再写领导汇报版，从技术版提炼业务能力和管理结论
3. 同步产出技术术语映射表，供 Phase 4 检查业务化表达

## 技术术语翻译规则

领导汇报版中不允许直接暴露：

1. 数据库表名
2. Java 类名
3. API 路径
4. 无解释的内部缩写

术语映射表示例：

```markdown
## 技术术语映射表

| 技术命名 | 业务名称 | 说明 |
|---|---|---|
| ota_upgrade_task | 升级任务管理 | 升级任务的生命周期管理表 |
| UpgradePushService | 升级推送服务 | 负责向设备推送升级指令 |
| POST /api/upgrade/push | 推送升级指令 | 触发设备升级的 API |
| FOTA | 固件远程升级（FOTA） | Firmware Over-The-Air |
```
