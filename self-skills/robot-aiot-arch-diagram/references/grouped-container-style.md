# 分组容器视觉语言（Grouped Container Style）

适用：任何"逻辑分组 + 组内条目"结构的直绘 SVG/HTML 图表——分层架构、阶段演进、泳道、对比矩阵、映射归因等。当图表存在 ≥2 个逻辑分组且每组含 ≥2 个条目时，本文件规则强制生效，优先级高于风格皮肤的默认容器画法（皮肤只改色值基准，不改层级结构纪律）。

**定位声明**：本文件是 `design-system.md` 未覆盖场景（分组容器图/分层容器图的具体版式）的增量规则：§3 字号阶梯、§5 箭头段色=目标分组主色仅在分组容器图内生效；通用样式数值仍以 `design-system.md` 为唯一权威。

目标：让直绘产物具备"容器-卡片-标签"三级纵深的组件感，杜绝文字裸排在底色带上的一级平铺画法。

## 1. 结构层级（三级纵深）

1. 分组容器必须三级纵深：画布底 → 分组容器（淡色底 + 3px 同族彩色边框 + rx=8）→ 子卡片（`#FFFFFF` 底 + 2px 同族彩色边框 + rx=8）
2. 禁止正文文字直接裸排在容器淡底上；容器底上只允许出现容器标签与专属侧栏药丸。说明性注记文字不得直接浮在容器淡底上，必须放入白色子卡片内或做成专属侧栏药丸（pill）
3. 边框宽度即层级：容器 3px / 子卡片 2px / 标签药丸与图例 1px；所有边框颜色取自所属分组色族，禁止无差别灰（唯一例外：中性工具容器可用 `#CCCCCC` 2px）
4. 容器标签：16px 粗体，置于容器内左上角，距左边缘和上边缘各 15px，颜色=该组文字深色
5. 列分隔优先用白卡阵列实现；确需细线时，线必须贯通容器内容区全高、上下内缩值一致（≤8px），1px，色值取所属分组色族主色的低透明度版本（如 `rgba(0,120,212,0.15)`）；禁止用中性灰分隔线（如 `rgba(17,24,39,0.12)`，即 §2 第 4 条禁用的第二套灰系）

## 2. 配色（色族身份）

1. 每个逻辑分组分配一个四值色族：主色（边框/箭头）、容器淡底、药丸淡底、文字深色。同图内任意两个分组的容器淡底不得相同
2. 默认参考族（可被品牌 token / 风格皮肤覆盖，覆盖时仍须保持四值结构）：
   - 蓝：`#0078D4` / `#E8F4FD` / `#D6EAF8` / `#004A8F`
   - 深蓝：`#005A9E` / `#F0F7FC` / `#DCEBF7` / `#003D6B`
   - 紫：`#9673A6` / `#F3E5F5` / `#E1D5E7` / `#6A4C7D`
3. 问题/风险/告警类条目固定用琥珀语义族：底 `#FFF8E1`、边框 `#FFA000`、文字 `#856404`；不得用正文中性色渲染负面信息
4. 全图只允许一套中性色阶：标题 `#003D6B`、正文 `#333333`、次要 `#666666`、分隔/工具边框 `#CCCCCC`；禁止混入第二套灰系（如 `#6b7280`/`#111827`/`#d1d5db` 与品牌蓝灰混用）
5. 纵深来源=明度差：容器淡底取主色相 90%+ 明度的浅色调，子卡片恒为纯白 `#FFFFFF`

## 3. 排版（字号阶梯）

1. 字号阶梯（1600~1800px 宽画布）：28 主标题粗体 / 15~16 副标题（斜体、`#666666`）/ 16 容器与区块标签粗体 / 14 强调句粗体 / 12 卡片标题粗体 / 11 卡片说明与药丸文字；相邻级差 ≤4px，每级只承担一种角色
2. 卡片内文字结构固定：12px 粗体标题 + 换行 + 11px `#333` 单行说明（380px 宽卡片下说明 ≤30 个汉字），整体水平垂直居中
3. 全局声明字体栈：`<style>text{font-family:'PingFang SC','Microsoft YaHei','Helvetica Neue',Arial,sans-serif}</style>`；编号类短代码（如 L1/S2）可用 `'SF Mono','Menlo','Courier New',monospace` 12px
4. 主标题+副标题水平居中于内容区宽度，副标题紧贴主标题下方（基线间距 ≤40px）；同一份图在 HTML 壳与 SVG 内只允许出现一次标题，禁止双写
5. SVG 文本禁止 `tspan` 与 `text-anchor="middle"` 混排（cairosvg 等部分渲染器会错位）；多行文本要么每行独立 `<text>` 元素，要么所有 `tspan` 统一显式重置 `x` 属性

## 4. 布局节奏

1. 同级卡片等宽等距：固定节距=卡宽+40px 沟（如 380 卡宽 → 420 节距）；容器内首卡距容器左边缘 40px
2. 横向容器带垂直节距=带高+50px（如 210 带高 → 260 节距）；容器带间隙 40~60px
3. 演进/流程箭头预留专用通道：容器外侧留 160~200px 宽空白通道，箭头只在通道内走正交折线（90° 拐角），禁止斜穿内容区
4. 内容必须占据容器高度 ≥70%；剩余死区 >60px 时压缩容器高度或补入药丸/注释，不得留空

## 5. 箭头与标签

1. 每一次状态跃迁画一段独立箭头，段色=目标分组主色，stroke-width=3，实心三角 marker 11×8、`markerUnits="userSpaceOnUse"`、fill=线色；禁止用一根通用箭头合并多次跃迁
2. 每段箭头配 12px 动作标签（文字色=目标分组文字深色），标签下必须垫白色不透明矩形（文字宽高各外扩 4~6px），防止压线

## 6. 组件（药丸 / 图例 / 汇总区）

1. 特征/属性条目做成药丸：高 32px（图例 28px）、rx=8、同组等宽（参考 180px）、11px 粗体、淡色底+1px 同族边框+同族文字色；竖排节距 40px，置于容器内专属侧栏
2. 图底部放图例行：每项复用对应分组的药丸 fill/border/文字色，高 28px、1px 边框、11px 文字；线型语义另加纯文字图例项
3. 需要全局总结时，在主结构下方另起白色汇总容器（`#FFFFFF` 底 + 2px `#CCCCCC` 边框 + rx=8），内含每分组一张淡底汇总卡（复用各自色族，关键句 14px 粗体、色=分组文字深色）

## 7. 元数据与无障碍

1. SVG 根元素带 `role="img"` + `aria-labelledby` 指向 `<title>`/`<desc>`；`<desc>` 用一句话描述图形结构逻辑
2. 每个图形元素标注 `data-graph-role`（background/container/edge/label/decoration），边加 `data-edge-id`、边标签加 `data-owner` 指向所属边

## 交付自检（Taste Gate 增补项）

- [ ] 无文字裸排在容器淡底上（容器底上只有容器标签与侧栏药丸）
- [ ] 边框宽度符合 3/2/1 层级，颜色全部取自分组色族
- [ ] 任意两个分组的容器淡底不同色；负面信息用琥珀族
- [ ] 全图只有一套中性色阶
- [ ] 每次跃迁一段独立箭头 + 白底动作标签
- [ ] 内容占容器高度 ≥70%，无 >60px 死区
- [ ] 标题只出现一次（SVG 内或 HTML 壳内，不双写）
