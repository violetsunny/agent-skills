# env-config — 目录结构唯一真源

本技能全部输出 / 生成 / 验证 / 读取 / 临时目录只在本文件登记。SKILL.md 与 prompts/ 仅引用登记项，不另行定义目录结构。

规则：

1. 新增目录、修改路径、调整输出范围 → 只改本文件；改后 grep 技能内旧路径的内联引用一并修正。
2. 正文内联路径为使用示例；与本文件冲突时以本文件为准，并修正内联。
3. 只写登记为「输出」的文件；验证链不改动 ADR 之外的任何项目文件。

## 目录登记表

作用根目录 = 目标项目根（当前运行项目）。

| 类别 | 路径 | 用途 |
|---|---|---|
| 输出 | `<项目根>/docs/adr/ADR-<三位数字编号>-<标题>.md` | ADR 归档（默认唯一落盘产物，编号连续递增） |
| 输出（可选） | 核查报告（verification-report.md 风格） | 仅执行验证链且用户要求完整报告时输出 |
| 输出（可选） | 修复前/修复后差异摘要 | 仅用户明确要求时给出 |
| 读取 | 用户指定的技术上下文/源文件 | ADR 内容依据 |
| 读取 | 联网核查源（官方文档入口/标准规范/仓库） | Verifier 断言核查路径 |
| 读取 | 技能内 `prompts/*.md`（critic/verifier/repairer） | 只读角色提示词 |
| 临时 | 无 | 本技能不落中间产物；确需临时文件只用 `/tmp` 且用后即删 |
