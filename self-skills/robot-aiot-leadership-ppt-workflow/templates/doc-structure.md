# 两份文档结构骨架（Phase 2）

契约来源：`references/phase2-audience-layering.md`。使用方式：先写技术明细版，再按受众表达策略提炼汇报版，两份共用同一数据池。

## 技术明细版

```markdown
# <项目> 技术明细版

## 一、系统概述
## 二、全流程图（Mermaid）
## 三、泳道图与角色分工
## 四、阶段拆解与异常处理
## 五、版本治理与配置机制
## 六、扩展能力与生态支撑
```

## 目标受众汇报版（默认领导层）

```markdown
# <项目> 汇报版（<目标受众>）

## 一、管理结论（每主题一句话）
## 二、分层架构描述
## 三、能力看板（数据表）
## 四、逐页能力摘要
## 五、数据口径说明
```
