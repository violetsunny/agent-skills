# 简报模板

1页内完成的技术方案简报，适用于决策评审和向上汇报。

```markdown
# {方案标题} — 技术方案简报

- **日期**：{YYYY-MM-DD}
- **作者**：{姓名/团队}
- **状态**：待决策 | 已决策

---

## 问题陈述

{2-3句话描述核心问题和为什么需要现在解决}

## 推荐方案

- **选定方案**：{方案名称}
- **核心做法**：
  - 要点1（关键实现方式）
  - 要点2（关键实现方式）
  - 要点3（关键实现方式）

## 关键优势

- 优势1（可量化收益）
- 优势2（可量化收益）
- 优势3（可量化收益）

## 主要风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 风险1 | 高/中/低 | 应对措施 |
| 风险2 | 高/中/低 | 应对措施 |

## 成本估算

- **开发成本**：{人天/工期}
- **资源成本**：{服务器/中间件费用}
- **运维成本**：{月度/年度运维开销}

## 决策需求

{明确需要决策者批准什么：预算/人力/时间窗口/技术方向}

## 时间线

| 节点 | 时间 |
|------|------|
| 方案评审 | {日期} |
| 开发完成 | {日期} |
| 上线发布 | {日期} |
```

## 校验清单

- [ ] 问题陈述 ≤3句话
- [ ] 推荐方案 ≤5个要点
- [ ] 主要风险 ≤3条
- [ ] 成本估算含开发+资源+运维
- [ ] 决策需求明确具体
- [ ] 整体可1页内展示

## 使用建议

- 面向非技术决策者时，减少技术术语，强调业务影响
- 面向技术决策者时，可补充关键架构图（Mermaid）
- 简报发布后，完整技术提案可作为附件页面链接
