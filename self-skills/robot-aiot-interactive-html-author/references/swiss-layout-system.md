# 登记版式系统（S 系瑞士 × M 系杂志）

## 定位

本文件是演示 deck 的"登记版式"硬约束库：25 个瑞士国际主义风格正文版式（S01-S25）与 10 个电子杂志版式（M01-M10），外加选择索引与内容-数据类型匹配规则。目的不是增加灵感，而是防止生成时"看起来像某种风格，但已经脱离登记骨架"。

1. 登记版式约束**结构与比例**（网格构成、px 尺寸、元素角色），不锁定类名；实现用 deck 自己的 token 体系（见 `design-system-standards.md`），结构骨架必须与登记一致
2. 每个正文页先选一个登记版式，在 `<section>` 上写 `data-layout="Sxx"` 或 `data-layout="Mxx"`
3. S 系与 M 系**同一 deck 不混用**：同名元素在两系语义不同（如大标题在 S 系是无衬线极细 200，在 M 系是衬线金句）；一份 deck 锁定一系
4. 全部尺寸按 1920×1080 固定画布锚定（1vw≡19.2px，1vh≡10.8px），代码一律写 px；字号/字重/下限细则见 `typography.md`
5. 主题节奏、chrome/kicker 分工、导航安全区、飞行前检查见 `web-slide-strategies.md`；翻页、入场、fragment 实现见 `interactive-mode-rules.md`

## 锁定机制（7 条硬规则）

1. 正文页必须来自登记版式（S01-S25 / M01-M10）；禁止临时发明未登记的正文结构
2. 需要图片时：单张大图 = S22；多图 = S15/S16 网格骨架改造成图片格；不要发明新的证据墙
3. 顶部中文标题默认左对齐、贴近左上内容轴；除 S03/S09/S10 登记陈述/分屏版式外，不把大标题放页面水平中心（M 系 hero 页 M01/M02/M07/M08 允许居中）
4. SVG 只画几何线条、圆、箭头、路径，不写可见文字（禁 `<text>`）；所有文字标签用 HTML 放网格、卡片或 caption 里
5. 图片槽位与生成比例绑定：先确定版式与槽位，再生成/裁剪图片（比例见 S22/S15/S16 条目与 M 系通用骨架）
6. 唯一登记的交互扩展：S08 地理插槽（原生 SVG 静态地图），仍是 `data-layout="S08"`，不是新正文页
7. 每页写代码前先列"页码 → data-layout → 为什么选它 → 图片槽位"；生成后按 `web-slide-strategies.md` 飞行前检查逐项过

## S 系设计基线

**配色**（`--accent` 由主题决定，见 `visual-style-presets.md`）

| token | 值 | 用途 |
|---|---|---|
| `--paper` | #ffffff | 纸白主背景 |
| `--ink` | #0a0a0a | 黑墨主文字 / ink 反转块 |
| `--accent` | 主题单色锚点 | 唯一强调色 |
| 三级文字灰 | primary / secondary / helper | 文字层级 |
| `--border-subtle` | #e0e0e0 | 1px 发丝细线 |

**排版**：拉丁无衬线系统栈 + mono 系统栈（见 `typography.md` 第二节）；字重 200 巨字 / 300 正文 / 600 小标；大标题保持 200、重点词与数字 300，不因样式 helper 残留 700-900 而加粗。拉丁巨字 letter-spacing -.04em、line-height 0.9-0.94；中文巨标题按 `design-system-standards.md` §15——字距归零、展示标题行高 1.15-1.25。mono 数字 `font-feature-settings:"tnum"`。

**网格与间距**：16 列网格 `repeat(16,1fr)` + gap 16px；间距常用档 8/12/16/24/32/40/48/64/80/96/160px。

**画布**：画布卡 1920×1080，直角无圆角，padding 上 60 / 左右 96 / 下 48px；背景实色 token，不用 3D 背景；split 页画布卡 `padding:0`，两个半屏各自控制（60px 69px 48px）。

**P0 结构对齐（每生成一页先过，违反 = 整页报废）**

1. **不二次叠加水平 padding**：画布卡已带左右 96px，页眉、主体、脚注都是其子元素，共用同一条 96px 边线；主体层再写 96px 就变成 192px，主体比页眉多内缩一圈、左右对不齐。主体 `padding:0`，垂直间距只用 grid gap
2. **kicker 必须在大标题上方**：小标与大标题是从属关系，必须 flex column 上下叠（gap 15px）；禁止 `grid-template-columns:auto 1fr` 挤成左右两列
3. **子块间距用 grid gap**：画布卡默认 flex column，页眉自带 margin-bottom 48px；主体多行（head/内容/footnote）首选 `display:grid;grid-template-rows:auto 1fr auto;gap:Npx`，次选 flex column + gap；禁在每个子块加 margin-top/padding-top 调间距（与页眉 margin 重叠撕裂）
4. **大字号必须限高**：一律用 `typography.md` 第一节双约束换算出的 px 值；底部分页安全区见 `web-slide-strategies.md` 导航安全区节

**卡片填充四型（互斥，禁混用）**

| 类型 | 角色 | 用法 |
|---|---|---|
| ink 黑底卡 | 反转 / 宣言 | hero 块、收束页一半 |
| accent 填充卡 | 唯一焦点 | 一组中突出一项 |
| 灰底卡 | 默认中性 | 多卡并列、统计卡 |
| 描边卡 | 锚点（非卡片） | hairline 分割框 |

禁止 accent 底 + 描边、灰底 + 描边等混用。

**装饰极简**：1px hairline 分隔；8×8 / 12×12 直角小方块替代圆点；点阵、描边圆环、叉矩阵（SVG mask 实现）。

**图片使用原则（S 系）**

1. 图片是网格中的"证据块"，不是装饰背景；必须有明确功能：案例、实拍证据、UI 截图、系统图、概念信息图
2. 容器直角、无阴影、无圆角；默认不加图片外框，由 caption 或页面网格承担层级
3. 白底信息图/流程图/UI 图容器背景必须纸白；禁灰底包白图、禁加描边；仅当图片边缘与页面无法区分时加一条顶部 accent 线，不给每张图套边框
4. 纪实照片 `object-fit:cover` 只裁底部/边缘；原始截图或文字密集图用 `object-fit:contain` 避免文字被裁
5. 按 S15/S16 槽位重新生成的图必须铺满槽位（cover），禁再 contain（否则小图漂在白框里）；contain 只用于必须保留原始比例的用户截图或文字密集图
6. 比例优先：S22 顶部横幅 21:9；S15/S16 多图格统一 21:9 或统一 16:10，不混用
7. 生成图保持单一 accent、直角纯色、无渐变/阴影/圆角；不把页眉、页脚、标题、页码、角标、边框、署名画进图片
8. 图片走本地文件（`images/{页号}-{语义}.png` 或用户提供素材），不外链

**版式多样性硬规则**

1. 7-8 页 deck 至少用 6 个不同 S 编号版式
2. 不允许连续 3 页使用同一种主体结构
3. "测试模板/看效果"类请求必须覆盖：封面、收尾、至少 1 个对比/时间线（S08/S11/S02）、至少 1 个结构图（S14/S17/S15）、至少 1 个图片版式（S22 或 S15/S16 图片格）
4. 图片页不等于新发明页：单图 S22、多图 S15/S16 改造

**动效原则**：每页一个语义化 recipe，与图形耦合——数字 scale 弹入、bar scaleY 拉起、圆环 stroke-dashoffset 描线、时间线节点序列点亮；不是统一 fade-up。缓动两档：productive `cubic-bezier(.2,0,.38,.9)`（120-240ms）、expressive `cubic-bezier(0,0,.3,1)`（400-700ms）。实现全部原生 CSS/WAAPI，入场排序走 `data-enter-order`（时长预算与接缝见 `keyframe-animation.md`，翻页触发见 `interactive-html-authoring.md`）；`prefers-reduced-motion` 降级按 SKILL.md 硬约束 12。

## S 系 25 个登记版式

### S01 · 目录封面
- 用途：整套 deck 起手 / 主题宣言；纯文字结构（主标题 + 副标 + 元信息），不承载数据
- 骨架：默认 accent 满屏（不是纸白底）；三行 cover-row（每行左 mono 大编号 + 右大标题文字）；页眉（左 deck 标题·编号 / 右日期 + 页码）；巨字 205px / weight 200；底部 1px 分隔线（accent 上用 rgba(255,255,255,.22)）+ lead 副标（max-width 52ch）+ meta 行（作者·日期 / 操作提示）
- 可选背景：ASCII 字符呼吸场（原生 canvas rAF，生命周期与 reduced-motion 降级见 `generative-art-and-canvas.md`）
- 动效：hero——字符场持续呼吸（启用时），文字 fade-up 序列入场（expressive）
- 注意：accent 满屏变体编号并入页眉，不再放大编号"01"；反白强调见 `typography.md` 第二节；与 S10 形成"开场全 accent ↔ 收尾半 accent"色彩闭环；accent 满屏不合内容调性时可用"左 ink + 右纸白对开"经典变体

### S02 · 纵向时间轴 + KPI
- 用途：演化对比、年代变迁、版本迭代（2-5 个时间节点）
- 适用：带量化数据的时间演化——每节点"年份 + 量化数值（倍数/单位数字，大字）+ 描述"三件套；只有节点名没数据改用 S11
- 骨架：顶部左对齐标题；中部纵向时间轴（左 12px 固定轴列：圆点 + 1px 虚线轴，圆点 `position:absolute;left:50%;translateX(-50%)` 与虚线对齐防错位；右侧节点信息）；底部四格 KPI 行
- 动效：节点按时间顺序由上到下点亮（圆点先 pop 再扩 → 文字横向滑入）

### S03 · 分屏陈述
- 用途：中心论点 + 一段解释；章节起始
- 适用：纯定性论断（一句话压缩到 8-12 词）+ 右栏解释；需数据支撑改用 S18；封面用 S01；纯口号无解释用 S09
- 骨架：双半屏 split——左半巨字陈述（184px 档 / weight 200，可 ink 或 accent 反白底），右半灰底解释栏（lead + 短段）；半屏 padding 60px 69px 48px
- 动效：左巨字按词序错峰升起（180ms/词）→ 右栏解释淡入
- 注意：陈述页大标题允许不走左上轴（锁定机制第 3 条例外）

### S04 · 六格
- 用途：6 个对等概念定义、6 项功能并列（数量必须 = 6；过少用 S05，过多用 S15/S16）
- 骨架：顶部左对齐标题；下方 2×3 六卡，单元间 hairline 分隔；每格：内联 SVG 小图标（棱角风格，stroke 1.5-2，24×24 viewBox；不自绘复杂插画）+ mono 编号 + 短标题 + 一行描述；每格只承载这四件，不放需展开的数据/段落
- 图片规则：可把卡片内部换成小图标，不放大图
- 动效：6 格 Z 形顺序点亮（L→R、T→B，90ms/格）

### S05 · 三层块
- 用途：三步流程、三类轻度对比、三大块并列（数量必须 = 3）
- 适用：结构同质、无强烈数据差异（数据可比改用 S06）；每块编号 + 标题 + 1-2 行描述
- 骨架：顶部左对齐标题 + 下方三大块横排（灰底直角卡）；标题需要更多篇幅时可用变体：左侧大标题 + 描述 + 顶部 hairline / 右侧三张水平堆叠子卡
- 动效：主标题先入 → 3 卡阶梯式从右滑入（140ms/卡）

### S06 · KPI 塔
- 用途：4 项数据用视觉高度表达层级差异
- 适用：4 项可比量化数据（必须有真实数值，bar 高度由数据决定）；无数据的概念列举禁用（那是 S04/S05）
- 骨架：左标题 + 右说明；下方 4 列均分，每列：顶部内联 SVG 图标 + 中段巨数 + 底部标签 + 柱底 accent 矩形 bar（高度由数据决定，最小 65px / 最大 389px）
- 动效：标签先入 → 数字 scale 弹入 → bar scaleY 0→1（`transform-origin:bottom`）

### S07 · 横向条形
- 用途：多项排名比较 / 占比对比（5-10 项）
- 适用：必须有真实百分比/评分/数值，bar 宽度由数据决定；严禁无量化数据的概念列举——编造数字会被识破（见 P0 匹配雷区）
- 骨架：顶部左对齐大标题；下半部条形列表，每行：文字标签 + 1px accent 条（0→目标宽）+ 末端数字
- 动效：标题先入 → 每行依序条宽 0→目标（`transform-origin:left`）+ 末端数字 count-up

### S08 · 双轨对照
- 用途：Before/After、A vs B、旧/新对比（必须正好 2 项，两侧结构同质）
- 骨架：左右两列 + 中线 1px 纵向长线；每侧：小标签 + 大字标题 + 段落/列表说明
- 登记扩展——地理插槽：地点、路线、城市关系、门店/校区/事件点位、人物住所关系内容，右列可替换为**原生 SVG 静态地图**：SVG 只画点 + 连线，不写可见文字，标签用 HTML 卡片；不引外部地图库，不做滚轮缩放/拖动交互（避免触发 deck 翻页）；仍是 `data-layout="S08"`
- 动效：中线 scaleY 0→1 先拉开 → 左右标题、文字镜像入场

### S09 · 点阵陈述
- 用途：第二张陈述页 / 章节切换 / 视觉透气页（同 S03 内容类型，加几何点阵装饰）
- 适用：口号、隐喻、章节切换；避免与 S03 连续两页陈述；常用作"概念定义"前的视觉调味页
- 骨架：中段 134px 档巨字三行宣言；右上 691px 方形点阵（SVG mask 实心点）+ 左下 346px 描边圆环矩阵（点阵/圆环严格在网格内，不贴边）
- 动效：文字逐行入 → 点阵 mask-position 从左推到右

### S10 · 分屏收束
- 用途：整 deck 收尾（每 deck 仅 1 页，不能在中间页使用——会与 S01 重复）
- 骨架：默认 split——左半 accent 满屏（+ 可选 ASCII 呼吸场）巨字宣言（151px 档 / weight 200）+ 署名行；右半纸白底 3 条 takeaway（编号 + 标题 + 一行说明），第 3 条用 accent 强调，把 accent 色从左半穿到右半完成缝合
- 动效：左标题字符序列升起 → 右三条 takeaway 尾随
- 注意：封面没用 accent 满屏时，改用经典 ink 双半屏变体（左 ink 巨字 / 右纸白 takeaway 列表），保持首尾重量对称

### S11 · 横向时间线
- 用途：多步骤流程（4-7 步）、时间演进（每步无数据）
- 适用：每步只有名称；要展开改用 S05；有量化数据改用 S02；循环结构禁用（那是 S14）
- 骨架：顶部大标题（`grid-template-columns:auto 1fr` 头部）；中部 1px hairline 横线 + 均布节点（8×8 直角方块点 + 上方 mono 编号 + 下方步骤名；编号属登记编号锚点，见豁免条款）
- 动效：节点沿轴左→右依次点亮（220ms/节点）
- 对齐注意：label 靠 `translateX(-50%)` 居中；动效做上下位移必须写完整 `transform:translate(-50%, Ypx)` 序列，只写 Y 会让 label 动画结束后偏离圆点

### S12 · 宣言 + ink 通栏
- 用途：阶段性结论、章节封底、口号 + 视觉强收束（用于 deck 中段；deck 终结用 S10）
- 适用："主张 + 简短说明 + ink 通栏宣言"三段结构，无数据
- 骨架：上半屏左侧小标签 + 大字 4 行宣言 + 右侧短段说明（右侧小字顶对齐于大字基线：`align-items:flex-start;padding-top:23px`）；下半屏 ink 通栏（`margin:0 -96px -48px` 取消父级 padding）+ 反白短句 + 图标矩阵
- 动效：大字三段错峰升起 → ink 通栏 scaleX 0→1 横向铺开 → 反白文字淡入

### S13 · 三力卡片
- 用途：3 个对等概念深化（数量 = 3，比 S05 承载更多文字）
- 适用：每卡 = 巨编号 + 标题 + 双列描述；01/02/03 为编号锚点而非真实数据；典型：三大反驳、三种力量、三大主张
- 骨架：左 5/16 ink hero 块（小标签 + 4 行标题 + 点阵装饰）/ 右 11/16 三张水平卡堆叠（灰底，巨编号 177px accent）
- 动效：左 hero 横移入 → 右 3 卡阶梯式从右滑入 → 巨编号单独 pop
- 注意：3 张卡必须统一灰底；需突出一张单独换 accent 卡；禁 accent 底 + 描边

### S14 · 闭环流程
- 用途：自学闭环、自动化流程（3-5 步循环，终点回到起点）
- 适用：线性流程禁用（那是 S11）
- 骨架：左 4 行编号步骤（顶对齐）/ 右 SVG 同心圆环 loop + 中央巨字"LOOP"；节点统一灰底直角方块（不用圆点交替色）；左右整体居中对齐（顶部对齐 + 高度等同）；SVG 只画几何，标签用 HTML
- 动效：左步骤纵向序列 → 圆环 stroke-dashoffset 描线 → 节点序列点亮

### S15 · 矩阵 + 巨数
- 用途：大量同类项展示（8-12 项）+ 底部一个汇总指标收束
- 适用：每项只承载短标题（无展开），底部巨数 = 汇总值（项目总数/总流量/总用户）；项数过少改用 S04
- 骨架：顶部左对齐标题（标题-矩阵间距 ≥97px）；中段 4×3 矩阵卡（每卡 130px 固定高，灰底直角禁描边，强调项单独 accent）；底部巨数（151px 档）+ 标签（`margin-top:auto` 推到底）
- 图片规则：多图可改造矩阵格——同组统一 21:9 或统一 16:10，图片格吸附原始网格槽位、容器铺满，不让图片自己决定宽高
- 动效：12 格随机棋盘渐显（随机延迟）→ 底部巨数 count-up
- 注意：卡片高度限定，防大数字溢出

### S16 · 微卡小报
- 用途：6 项小卡并列（快讯、tip 集合、特性概览；数量 = 6）
- 适用：比 S04 内容更碎，适合快讯类；每项主文短 + 小字注脚

- 适用：严格三层嵌套关系（技术栈层级、生态分层、影响力辐射）；非三层结构禁用——扁平用 S04，层级不清用 S05

- 适用：每论点 = 小标签 + 一句标题 + 段落 + 一个底部巨数（百分比/年份/倍数，真实数据）

- 动效：三列垂直递进 → 底部巨数 count-up
- 注意：巨数字号统一，只用颜色突出最后一列，不用粗体

- 适用：每项 = 编号 + 大字标题 + 一段描述；无数据维度，纯定性；比 S05 更平均、比 S06 更纯文字
- 骨架：顶部 80px accent 短发丝顶线 + 大字双行标题；下方 4 列均分卡（每卡顶部"— 01 / XXX"编号锚点 + 大字标题 + 段落）

- 注意：禁用 9px 圆形装饰点（不符合直角语言），用 mono 小标文字代替

### S20 · 账单式 KPI
- 用途：4-6 行核心数据账单式展示
- 适用：每行必须有真实数值 + 标签 + 图标；适合财务数据、KPI 仪表板、关键指标列表；比 S06 容纳数据更多但视觉化弱（无 bar 高度对比）
- 骨架：每行一道 hairline 分隔；左侧巨数（173px 档，必须限高防底部行被挤出）/ 中部标签 / 右侧内联 SVG 图标
- 动效：每行数字升起 → 标签左滑 → 图标 pop（180ms/行错开）

### S21 · 规格说明书
- 用途：产品规格、benchmark 数据、性能基线（必须有真实多维数据，3 KPI + 9 根竖线 = 12+ 数据点）
- 定位：deck 中数据密度最高的版式
- 骨架：左 4 行大标题；中部 3 KPI（顶部 hairline + 数字 + 单位）；右下 9 根高低不一的垂直竖线（底对齐、不超出右边距）；底部巨数 + 目标 + 三个 tag + 右下页码
- 动效：hero 区淡入 → 标题入 → KPI 顶线一根根画出 → 底部巨数 pop → 竖线从底部 scaleY 弹起（50ms 错开）

### S22 · 图片主视觉
- 用途：案例展示、产品图 + 数据落地、章节封面带图
- 适用：必须有真实图片资源 + 3 个核心数据；没有真实图源禁用（占位灰图破坏视觉）
- 骨架：顶部 648px 全幅图 + 左上纸白底标题块叠加（top 119px / left 96px / padding 35px 61px / max-width 768px / 标题 97px 档）；下部长说明（25px，max-width 48ch，不贴图片下沿——统一加顶部缓冲）+ 三列 KPI（82px 档限高；小字 `margin-top:auto` 锚定列底防溢到分页圆点；列高度统一，grid 拉伸不用 `align-items:start`）
- 图片规则：主图按 21:9 生成/裁剪，关键主体放中央安全区；照片 `object-fit:cover` + `object-position:center 35%`（人像/会议场景禁 `top center` 截人脸）；信息图/UI 截图必须重新生成接近 21:9 并用 contain，或保证核心内容在中央 70% 安全区
- 动效：图缓慢 zoom-out（scale 1.05→1）→ 白块 scaleX 0→1 推开 → 三 KPI 顶线依序画出

### S23 · 代码版式
- 用途：核心代码片段展示（运行时逻辑、配置示例、关键实现）
- 适用：单文件单语言、摘录 ≤20 行；长代码只留关键段并用 `// …` 省略注释；纯文字结论不伪装成代码
- 骨架：顶部左对齐 kicker + 大标题；主体 `<pre>` 代码卡（ink 黑底反白或灰底，直角无阴影，padding 24-32px，mono 系统栈 20-24px / line-height 1.6）；文件路径放卡顶 mono 小标（uppercase、helper 灰）；语法着色用纯 CSS span 类——关键字映射 accent、字符串/注释映射三级文字灰，不引任何外部高亮库或 CDN
- 动效：代码行自上而下逐行淡入（stagger 60-90ms/行）；关键行可单独 accent 高亮延迟点亮
- 注意：零外部依赖是硬约束（SKILL.md），任何语法高亮库/CDN 禁用；行号如需要用 mono 右对齐 helper 灰（属编号豁免）；ink 黑底卡上文字反白、accent 保持可读对比

### S24 · Diff 对照
- 用途：代码/配置 before-after 逐行对照（迁移效果、修复补丁、重构前后）
- 适用：行级增删对照，add+del+ctx 合计 ≤16 行；概念性 Before/After 用 S08，不用本版式；多文件对照拆多卡分栏或拆页
- 骨架：顶部左对齐标题；主体 diff 卡（直角、1px `--border-subtle` 描边、mono 20-22px / line-height 1.6）；卡顶文件头条（灰底 + uppercase mono 小字路径 + 底部 hairline）；每行 `white-space:pre`——add 行绿底 `rgba(26,175,108,.12)`、del 行红底 `rgba(224,68,90,.12)`、ctx 行 secondary 灰；卡底部一行结论（helper 灰小字）
- 动效：del 行先淡入 → add 行逐行替换点亮（80ms/行）→ 底部结论最后淡入
- 注意：绿（#1aaf6c）/红（#e0445a）是 S 系单 accent 原则的唯一登记例外，仅作低饱和底色与行文字色，不扩散到其他元素；卡片直角、无圆角、无阴影

### S25 · 检查清单
- 用途：上线前检查、验收清单、行动项跟踪（4-8 条）
- 适用：每条 = 一行短句 + 可选右侧 mono 标签；超 8 条拆页；有先后依赖的步骤用 S11，层级任务用 S05
- 骨架：顶部左对齐标题；主体单列列表（max-width 820-960px）；每行 flex——22×22 直角方框 checkbox（border 2px secondary 灰；完成态 accent 或语义绿填充 + 反白 ✓ + 文字删除线降为 helper 灰）+ 正文 24-26px + 右侧 mono 小标签（helper 灰，`margin-left:auto`）；行间 hairline 分隔
- 动效：行 stagger 从左滑入（120ms/行）；完成项 ✓ 依序 pop
- 注意：checkbox 必须直角（S 系禁圆角）；右侧标签是内容语义标签（#ci、#fonts 类），不是编号眉标；完成/未完成两态必须同页可见区分（填充 + 删除线），不能只靠颜色

**编号元素豁免条款**：SKILL.md 硬约束 8 禁止编号眉标、装饰状态点、版本号页脚；登记版式内的 mono 编号/页码在**登记位置豁免**——仅限：页眉左右两侧（deck 编号、页码）、列顶编号锚点（S11/S18/S19 等）、矩阵格编号（S04/S13/S15/S16）、时间线节点编号（S02/S11）、代码/diff 行号（S23/S24）、清单右侧语义标签（S25）。登记位置之外仍禁止编号眉标。

## M 系通用骨架

```html
<section class="slide" data-theme="light|dark|hero-light|hero-dark" data-layout="Mxx">
  <!-- 页眉 chrome：左 栏目标签（跨页稳定）/ 右 幕号 + 页码 -->
  <!-- 主体 frame -->
  <!-- 脚注 foot：左 页面说明 / 右 短标记 -->
</section>
```

1. 每页必带主题四档之一（light / dark / hero light / hero dark）；hero 页用于章节封面/开场/收束/转场，非 hero 页用于正文；节奏硬规则与 8 页模板见 `web-slide-strategies.md`
2. 页眉与脚注是可选但推荐保留的四角元数据；chrome 与 kicker 的内容分工见 `web-slide-strategies.md`
3. 网格常用配比：6:6（对半分）/ 7:5（文字为主 + 辅助图）/ 8:4（大段文字 + 小图数据）/ 三列均分 / 3×2 六格；gap 水平 58px 竖直 43px（可单独覆写）
4. 图片比例规范：左文右图主图 16:10 或 4:3；多图网格统一固定高度（281px 档，图注在框内占约 43px、实际图展示 ≈238px；标题更长或加说明行降到 238px）；小型面板组统一 173px 或 194px（同组必须同高）；左小图右文 1:1 或 3:2；全屏主视觉 16:9；信息图/截图再设计 16:9 或 16:10 + contain；图文混排小插图 3:2 或 3:4。禁止原图奇葩比例（如 2592/1798）
5. 图片垂直对齐：图片跟正文内容区对齐，不默认贴大标题顶端——左列是"kicker + 大标题 + 正文 + callout"时，右列图片 `margin-top:76-97px`；横向长条截图不硬拉满宽，改极宽横图素材或拆 2-3 个局部面板拼排
6. 图片定位反模式：`align-self:end` 在 grid 外无效会让图掉到文档流末尾堆底；`position:absolute;bottom:0` 会被脚注与分页遮挡；图文混排必须用 grid 结构（默认 `align-items:start` 图自然贴顶）；要"图片底对齐左列 callout"时，用左列 flex column + `justify-content:space-between`（callout 自己贴左列底），右列保持顶对齐；图容器作 flex 子项时 `align-self:start` 只定位不防收缩，须显式 `width:100%`，否则图缩到内容宽；右栏/details 栏容器必须 `overflow-y:auto` + 细滚动条（`scrollbar-width:thin` + webkit 6px），展开内容超画布高度时裁切即不可读
7. 两段式页面（顶部标题 + 下部长正文/引用/图表）标题-内容间距 65-86px；复杂内容页大标题与下方内容分层，下方内容用左右两端对齐的 grid，不全堆一条中轴线
8. M 系 hero 页（M01/M02/M07/M08）大标题允许水平居中；正文页左对齐
9. 动效 recipe 绑定原生体系：入场排序走 `data-enter-order`；M06 分步推进用 fragment 机制（见 `interactive-mode-rules.md` 页内分步揭示）；动效被禁用/跳过时所有内容必须可读（opacity 兜底为 1）
10. `<details>` 折叠取舍口径：删掉该卡本页结论仍成立则折叠（补充细则、笔记章节展开、素材图参照），不成立则常驻（定义、职责表、代码示例）；全 deck 统一执行，不逐页临场改口径；summary 蓝字 ▶ 前缀

## M 系 10 个登记版式

### M01 · 开场封面
- 主题：hero dark；内容整体垂直居中（内容区 min-height 864px + `align-content:center`）
- 骨架：kicker（场合·主讲人）→ 巨字主标题（192px 档）→ 副标题 → lead（max-width 1152px，一段话钩子）→ meta 行（作者·身份）
- 动效：hero recipe，慢节奏仪式感依次淡入
- 注意：页眉不写页码，封面自成一体

### M02 · 章节幕封
- 主题：hero 档；全 deck 单色系——dark 系 deck 用 hero dark、light 系 deck 用 hero light，禁多幕间明暗翻面；呼吸节奏靠 hero 档与非 hero 档轮换及版式变化制造
- 骨架：极简三件——kicker（Act N）→ 巨字标题（163px 档，可按长短微调）→ 一行 lead（max-width 1056px）

### M03 · 数据大字报
- 主题：light（数字需纸白底；dark 系 deck 用本版式时按 token 映射保持全 deck 单色系，禁插入异主题页，节奏靠版式变化制造）
- 骨架：kicker → 大标题 → lead → 3×2 六格统计卡（每卡：英文小标签 → 大字数字 → 注释）；数字 2-3 位字符，过长用 K/M 简写
- 注意：间距实测上限——主体 padding-top 32px + lead margin-bottom 22px + grid margin-top 22px，六格在 16:9 不压脚注；内容更多时先删卡片，不压缩脚注空间

### M04 · 左文右图
- 主题：随 deck 单色系取 light 或 dark（全篇统一，禁逐页明暗交替）；正文节奏主力，节奏靠版式与密度变化制造
- 骨架：7:5 grid；左列 flex column + `justify-content:space-between`——上部 kicker + 大标题（138px 档，单行可 nowrap）+ lead，底部 callout 引用 + 出处；右列 16:10 或 4:3 图片 + 框内图注
- 注意：右列图片禁 `align-self:end`；图片用标准比例，不用原图奇葩比例

### M05 · 图片网格
- 主题：light（截图需亮底）
- 骨架：kicker → 大标题 → 3×2 grid，每格固定高度 281px（写死高度，不用 aspect-ratio，否则网格撑破）；图片 cover 只裁底部；图注在框内（占约 43px，实际图展示 ≈238px）；标题更长或加说明行降到 238px
- 适用：多平台截图实证、多案例对比

### M06 · 两列流水线
- 主题：light（流程图需清晰）
- 骨架：分组（组标题 + 步骤行）；每步固定结构：编号 → 标题 → 描述；单行 ≤5 步，超出换第二组；组间 39px 间距 + 顶部细分隔线
- 动效：分步手动推进——步骤默认 `opacity:.15`，按 →/空格/滚轮下滑一次点亮一步，全部点亮完才翻页（fragment 机制）；制造演讲互动感

### M07 · 悬念问题页
- 主题：hero 档，随 deck 单色系取 hero dark/light（强视觉冲击；禁在 light 系 deck 单独用 hero dark 翻面）
- 骨架：留白最大化，只放一个问题——kicker → 巨字三行（134px 档，手工 `<br>` 断在语义处）→ 一行 lead 点破
- 用途：幕收束、留悬念

### M08 · 大引用页
- 主题：hero 档，随 deck 单色系取 hero dark/light（dark 系金句仪式感靠暗底；light 系靠整页留白与字号档位制造同等仪式感，禁为金句页单独翻面）
- 骨架：整页留白——kicker → blockquote 系统衬线栈金句（111px 档 / weight 700 / line-height 1.2，每行 `<span>` 块级）→ 外文原文或译文 lead（opacity .65 制造层级）→ meta 行出处·日期
- 动效：quote recipe——一句一句揭示（550ms stagger 慢节奏）
- 注意：blockquote 单独放大字号，不复用页面主标题档；中文金句按 §15（「」引号、禁伪斜体）

### M09 · 并列对比
- 主题：light（双列需清晰）
- 骨架：6:6 grid；左列（旧）`opacity:.55` 视觉弱化，右列（新）满亮度突出；两列 `border-left:3px solid currentColor` + padding-left 做引用块感；每列结构统一：kicker → 中标题 → 要点列表（21px 档 / line-height 1.55）
- 动效：directional——左进 → 分割 → 右进

### M10 · 图文混排
- 主题：随 deck 单色系取 light 或 dark（全篇统一，禁逐页明暗交替）
- 骨架：8:4 grid（正文主导，图片辅助）；左列多层级：kicker → 大标题 → lead → 正文段落（22px 档 / line-height 1.75）→ callout 引用；右列竖版 3:4 或方形 1:1 辅助图（避免与左列文字抢注意力）
- 适用：页面信息量偏大的场景（不像 M04 只承载一句金句）

## 常犯错误（P0 检查项）

1. ❌ 卡片加 `border-radius` → ✅ 必须直角
2. ❌ accent 填充卡上又加描边 → ✅ 填充类型互斥
3. ❌ 自绘复杂 SVG 图标 → ✅ 内联 SVG 棱角风格（stroke 1.5-2，24×24 viewBox）
4. ❌ 时间线圆点用 grid `justify-self` 对齐虚线 → ✅ 轴列固定 12px + 圆点绝对定位
5. ❌ 大字号不限高 → ✅ 一律用 `typography.md` 双约束换算 px
6. ❌ O 键总览网格克隆页看不到带动效内容 → ✅ 克隆 slide 加可见性 override（`opacity:1;animation:none`）
7. ❌ 所有页同一个 fade-up recipe → ✅ 每页一个语义化 recipe，与图形耦合
8. ❌ 标题-卡片间距 <54px → ✅ 章节级标题至少 97px
9. ❌ 9px 圆形装饰点 → ✅ 8×8 直角小方块 / mono 小标文字
10. ❌ 装饰元素超出页面边距 → ✅ 严格在网格内，不贴边

## 禁止清单

1. 顶部中文大标题 `text-align:center` 禁止（S03/S09/S10 登记陈述/分屏版式除外；M 系 hero 页按 M 通用骨架第 8 条）
2. 顶部标题写进右侧栏造成视觉居中，禁止
3. 未登记正文结构发明禁止（临时图文分栏页、多图证据墙、三圆自绘页等）
4. 图片容器灰底包白底信息图，禁止
5. SVG 写 `<text>` 可见标签，禁止
6. 照片默认 `object-position:top center`，禁止
7. 卡片圆角、阴影、填充 + 描边混用，禁止
8. 大字号不做双约束限高，禁止
9. 靠降低字号解决拥挤，禁止——先压缩文案、拆页或换登记版式
10. 无真实数据编造 KPI/数字，禁止（无数据内容用定性版式）
11. 装饰元素超出页面边距、9px 圆点装饰，禁止
