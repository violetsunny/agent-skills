# 设计系统内化标准

本文件是本技能内化的设计系统标准，不是索引。
只保留适合"1920x1080 固定画布领导汇报页"的部分；已剔除 App/网页专属内容（触控目标、导航栏、SF Symbols、滚动动效、深色模式自动切换等）。
本文件是设计系统细则的权威来源；本技能其他文件中的设计系统条款是其摘要。

## 第一部分：语义 token 与层次体系

### 1. 色彩角色与音调配对

页面 token 按语义角色使用，映射到本技能既有变量：

| 语义角色 | 本技能变量 | 用途 |
|---|---|---|
| `primary` | `--primary-color` | 最高强调：结构线、重点数字、标题强调 |
| `on-primary` | 主色上的文字 | 主色填充块上的文字/图标，必须与主色成对 |
| `secondary` | `--secondary-color` | 次级强调 |
| `tertiary` | `--tertiary-color` | 补充分类色 |
| `surface` | `--surface-color` | 页面默认背景 |
| `surface-container` | `--surface-muted` 及扩展档 | 容器背景（见 §2 层次） |
| `on-surface` | `--text-primary` | 任何 surface 上的主文本 |
| `on-surface-variant` | `--text-secondary` | 低强调文本（说明、注释、来源） |
| `outline` | `--outline-color` | 重要边界（输入框、关键卡片描边） |
| `outline-variant` | 更浅一档分隔色 | 纯装饰分隔线 |

配对规则：

1. 音调配对锁定：只把成对角色组合使用（`primary`+`on-primary`、`surface-container`+`on-surface`），禁止任意交叉，否则对比度失控
2. 分隔线用 `outline-variant` 一档，不用 `outline`；`outline` 只给"重要边界"
3. 低强调文本（脚注、来源、说明）统一走 `on-surface-variant`，不与正文抢权重
4. `on-primary` 禁止硬编码 `#fff` / `#000` 顶替：主色明度跨度大（近白到近黑），没有任何单一字面量在所有主色上可读——实测近黑主色配深色文字对比度仅 1.01:1，完全不可见而版式乍看无异常。每套预设的 `on-primary` 取白 / 近黑中按 WCAG 相对亮度公式（实算法见 `premium-review-fix.md` 对比度实测法）与其主色实算 ≥ 4.5:1 的那个

### 2. 用色调表面表达层次，不用阴影堆层次

核心原则：层级靠 surface 明暗差，不靠阴影。

1. 容器层级用 5 档 surface 明度表达：`lowest → low → default → high → highest`
2. 抬升一级的做法：把当前 surface 向 `primary` 色调偏移约 5%-11%（浅底加深一档、深底提亮一档），而不是加阴影
3. 阴影只在背景杂乱、需要额外隔离时才用，且必须带背景色调（见 `premium-design-standards.md` 色彩纪律）
4. 嵌套卡片每深一层，surface 升一档；同一页 surface 档位数不超过 3 档，避免层次噪音

### 3. 字级体系（1920x1080 具体值）

| 字级 | 建议字号 | 用途 |
|---|---|---|
| `Display` | 56-80px | 封面核心标题、极少数年度/总数大字 |
| `Headline` | 36-44px | 页面主标题、一级区块标题 |
| `Title` | 24-30px | 卡片标题、分栏标题 |
| `Body` | 16-20px | 正文、图表说明、列表 |
| `Label` | 12-14px | 标签、徽章、脚注、页码 |

规则：

1. 相邻字级差至少 2px，靠字重和字号梯度拉开层级，不靠尖叫式超大号
2. 主数字建议 ≥ 28px，用 `tabular-nums`
3. 每级只取一个固定值落 token，不在同级内随意漂移

### 4. 形状与间距

1. 圆角档位 `8 / 12 / 16 / 24px`，胶囊用 `9999px`（仅按钮、标签、徽章）
2. 不直接写魔法圆角值，统一引用档位变量
3. 间距走 8px 基线：`8 / 16 / 24 / 32 / 48px`
4. 内容区不贴边：画布四周至少留 `32-48px` 安全边距

### 5. 反模式（禁止）

1. 硬编码颜色：一律用变量，不散落 hex/rgb
2. 忽略音调配对：任意交叉 `on-*` 与底色
3. 用 `outline` 画装饰分隔线
4. 默认用阴影表达层级
5. 直接写 `border-radius` 魔法值

## 第二部分：清晰与层次判据

### 6. 四支柱落成判据

把"清晰 / 尊重内容 / 层次 / 一致性"四个原则落成汇报页可检查的判据：

**清晰**
1. 每个元素都有明确作用，删掉任何一个会损失信息
2. 领导 30 秒内能读出核心结论，无需解释
3. 视觉层级一眼可辨：标题 > 结论 > 主数字 > 图表 > 说明

**尊重内容**
1. UI 壳层衬托内容，不与内容争抢注意力
2. 装饰降到最低：无多余边框、底纹、图形
3. 背景与描边克制，让数据和结论成为主角

**层次**
1. 用 surface 明暗差和轻阴影表达前后关系
2. 层级服务于重要性：越重要的内容越靠前
3. 不做无意义的堆叠和视差

**一致性**
1. 全套汇报共用同一套 token、字级、圆角、间距
2. 同类元素同样呈现（所有卡片标题同字级、所有脚注同样式）
3. 遵循既定的页面类型骨架，不逐页发明

### 7. 文本层级用语义强调色

文本层级不靠字号一种手段，配合语义明度：

1. 主文本用 `--text-primary`（全强度）
2. 次要文本用 `--text-secondary`（约 60% 强度）
3. 辅助/来源信息再降一档（约 30-40% 强度）
4. 同一页文本明度档位不超过 3 档
5. 用字重（400/500/600/700）配合层级，不只靠字号放大

### 8. 同心圆角规则（嵌套容器）

嵌套容器的圆角必须同心，公式：

```
外层圆角 = 内层圆角 + 内外层之间的内边距
```

示例：内层卡片圆角 `12px`，外层壳与内层间距 `8px`，则外层壳圆角 = `12 + 8 = 20px`（就近取档位 `24px` 或精确 `20px`）。
禁止内外同圆角或外小内大，那会破坏同心视觉。

### 9. 对比度与可读性

1. 正文对比度 ≥ 4.5:1（WCAG AA）
2. 大字（≥ 24px 或加粗 ≥ 19px）≥ 3:1
3. 关键数字、结论与背景对比要足够，不靠颜色单独传达
4. 浅色底不用过浅灰字，深色底不用过暗字

### 10. 默认实底，毛玻璃需显式请求

1. 默认用实色背景，保证可读性和渲染稳定
2. 毛玻璃/模糊只在用户明确要求时使用，且须提供实底降级
3. 图表区和数据区永远不用毛玻璃打底

## 第三部分：占位材质与单色读图

### 11. 单色占位材质系统

无真实图片/截图素材时，用单色 ink 阶梯画占位材质，不用彩色 stock 图、不用 div 拼假截图（呼应 `premium-design-standards.md` AI 痕迹清单第 7 条）：

| 档 | 不透明度（相对 ink 色） | 用途 |
|---|---|---|
| ink | 100% | 文字、关键轮廓 |
| L1 | 72% | 一级图形元素、图形主体轮廓 |
| L2 | 45% | 次级元素、地平线、骨架线 |
| L3 | 18% | 底板、扫描线、大面积纹理 |
| L4 | 8% | 最深层底板、内凹 vignette |
| hair | 14% | 1px 发丝线边框、分隔线 |

规则：

1. 相邻档不透明度比 ≥1.6x，否则视觉分不出档
2. 文字永不低于 L1（72%），可读性优先
3. ink 色取页面 `--text-primary`，不另引黑色

### 12. 无色深度四板斧

单色材质上表达深度，按顺序用，前一招不够才上下一招：

1. 明度台阶：升/降一档 surface（L3 板上叠 L2 元素）
2. hairline：1px 发丝线（14%）勾边分离前后层
3. 负空间：拉大间距表达分组，间距差即层级差
4. 细纹理：扫描线 / grain 区分材质面

阴影只允许无色弥散（黑低透明大模糊）；禁彩色阴影、禁硬偏移阴影——除非所用风格预设明确要求硬阴影（见 `visual-style-presets.md` blockframe / creative-mode / daisy-days）。

### 13. 黑白读图签名表

占位图形去掉颜色后仍须能被认出类型，按签名画法：

| 类型 | 签名画法 |
|---|---|
| 屏幕/设备 | 真实设备比例（16:9 / 9:19 等）+ 圆角档位 + hairline 边框 + L3 扫描线 + L4 内凹 vignette |
| 图片/照片 | 4:3 L3 板 + L2 地平线与圆盘（偏角落，不居中） |
| 卡片/内容块 | L4 板 + hairline 边框 + 两条骨架线（宽 100% / 62%） |
| 人/头像 | 圆形 |
| 品牌/logo | 圆角方形 |
| 图表 | 平涂单色，禁渐变、禁 3D、禁阴影 |

### 14. Accent 与渐变限制

1. accent 色每个构图最多 1 个元素（一个数字、一个图标、一条强调线）；超过即装饰不是强调。页面级面积占比见 `premium-design-standards.md` 布局纪律
2. 六个禁用默认紫蓝 hex（AI 生成界面高频色）：`#7c3aed` `#2563eb` `#6366f1` `#8b5cf6` `#a855f7` `#4f46e5`；无品牌依据不作默认装饰色（品牌色例外条款见 `premium-design-standards.md` 色彩纪律）
3. 渐变只允许四类：
   - 物理表面渐变：模拟真实材质光影（金属、玻璃、天空）
   - sheen sweep：高光扫过 `linear-gradient(90deg, transparent, rgba(255,255,255,0.75), transparent)`，仅作瞬时动画（实现见 `animation-fx-catalog.md` shimmer-sweep）
   - scrim：图片/文字上的可读性保障层（单向透明到半透明）
   - 主体即渐变：内容本身在讲渐变或色彩过渡
4. 四类之外的渐变 = 装饰性渐变，默认禁止

## 与高级感标准的关系

- 本文件管"设计系统的角色与层级"（token、字级、圆角、层次）
- `premium-design-standards.md` 管"反模板化与高级感"（设计解读、一致性锁定、AI 痕迹）
- 二者冲突时：图表真源约束 > 本文件 token 规则 > 高级感风格偏好
