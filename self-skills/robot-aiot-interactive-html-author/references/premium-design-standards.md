# 高级感设计标准

本文件是本技能内化的高级感设计标准，不是索引。
适用对象：1920x1080 固定画布的汇报逐页 HTML，面向目标受众（领导层/技术同行/外部客户/大众，未指定默认领导层）。
与网页场景的差异已在此改写：无响应式、无滚动动效、单页静态、中文内容、按目标受众分档设计。

## 1. 设计解读（先读题，再动手）

生成任何页面前，先输出一行设计解读：

> 解读为：<页面类型> 页，面向 <受众>，<视觉语气>，采用 <风格基调>。

示例：

- "解读为：数据看板页，面向集团领导决策，克制严谨语气，采用克制商务基调。"
- "解读为：封面页，面向外部汇报场合，品牌庄重语气，采用首页架构图主色基调。"

解读信号：

1. 页面类型：封面 / 架构图 / 数据看板 / 流程 / 案例对比 / 尾页
2. 受众：领导 30 秒扫描，结论先于细节
3. 既有品牌资产：Logo、首页架构图主色、既有图表 HTML（真源，不可动）
4. 隐性约束：数据必须真实可溯源，不追求网页感

上游 form 五问（受众 / 场景 / 核心主张 / 情绪基调 / 交付形态）由上层 workflow 采集，本节消费其产物映射到设计决策：受众→礼让观众维（§12）、情绪基调→风格基调与预设温度（`visual-style-presets.md` §2 预设标注四字段）、核心主张→结论先于细节、交付形态→画布与导出规格（`content-imagery-and-infographic.md` 衍生交付形态规格）；不在此重复五问表。

解读不明确时最多问一个问题；能从上下文推断就直接声明并继续。

## 2. 三档刻度（领导汇报默认值）

| 刻度 | 默认值 | 说明 |
|---|---|---|
| DESIGN_VARIANCE | 4-5 | 1=完全对称，10=艺术化混乱。汇报页保持克制，允许不对称分区，禁止炫技 |
| MOTION_INTENSITY | 2 | 幻灯片为静态单页，任何档位都不做滚动动画。1 档＝仅翻页切换，页内无入场动画（纯静态版恒为 1 档）；2 档（默认）＝轻量入场：`interactive-mode-rules.md` 的 `data-enter-order` 依次入场＋数字滚动/图表描绘，一次性不循环，入场总时长 ≤2s；3 档及以上＝ambient 呼吸、canvas FX，仅用户明确要求时升档并声明。动画属性仅限 transform/opacity/filter，reduced-motion 下降级为即时切换 |
| VISUAL_DENSITY | 4-6 | 封面/结论页取低值（留白多），数据看板页取高值 |

规则：

1. `VISUAL_DENSITY >= 7` 时，所有数字必须用等宽或表格数字（`font-variant-numeric: tabular-nums`）
2. 同一套汇报内各页刻度保持一致，不逐页漂移
3. 用户明确要求更活泼或更克制时，才调整刻度并声明

## 3. 风格基调（三选一，整套汇报锁定一种）

### A. 克制商务（默认）

- 浅色底（白或暖骨白 `#F7F6F3` 一类），单一强调色
- 容器用 `1px` 浅色描边 + surface 明暗差表达层次，几乎不用阴影
- 适合：绝大多数内部汇报

### B. 深底科技

- 深底用近黑而非纯黑（`#0A0A0A`-`#16324F` 一类），文字用灰白而非纯白
- 强调色单一，数据密集区用等宽数字
- 适合：技术架构、平台能力类汇报；需与品牌主色协调

### C. 暖调编辑

- 暖白底 + 大标题排版对比 + 低饱和点缀色（浅红 `#FDEBEC`/浅蓝 `#E1F3FE`/浅绿 `#EDF3EC`/浅黄 `#FBF3DB` 一档，文字用对应深色）
- 适合：案例、叙事、总结类页面

锁定规则：一套汇报只选一种基调；中途换基调等于换了一套 PPT，禁止。
交互演示 deck 或用户指定视觉风格时，可改用 `visual-style-presets.md` 的整套预设；预设与三档基调互斥，选定后同样整套锁定。

## 4. 排版纪律

1. 中文字体栈用 `"PingFang SC", "Microsoft YaHei", sans-serif`；数字和西文可配一个有性格的字体（如 `Geist`、`DIN`、`Barlow`），但全套汇报最多两个字体族。自定义字体必须随稿捆绑或确认渲染环境可用，否则退回默认字体栈，避免离线渲染掉字
2. 标题层级靠字重和字号梯度拉开，不靠尖叫式超大号；相邻字级差至少 `2px`
3. 页面主标题最多 2 行；超过 2 行是字号或文案错误，不是容器错误
4. 强调标题中的某个词：用同字体的加粗或变色，禁止混入另一个字体族
5. 正文行高 `1.3-1.6`，单行宽度控制在约 65 字符（中文约 32 字）以内
6. 大数字用 `tabular-nums`，同一列数字右对齐或小数点对齐
7. 全大写小标签（eyebrow）整套汇报最多每 3 页出现 1 次；多数页面标题本身足够，不需要眉标
8. 禁止竖排旋转文字、十字准星装饰线、纯装饰性分隔线
9. 暗底排版补偿：深底上正文降一档字重（500→400 或 400→350）、行高加 `0.05-0.1`、展示大字加 `0.01em` 字距；浅字深底视觉膨胀，不补偿会显臃肿
10. 字重对比拉层级：同页允许 300 细体正文与 900 特重展示体的大跨度对比；字重差 ≥300 即算一级层级，与字号梯度等效
11. OpenType 数据特性：数字列 `font-variant-numeric: tabular-nums`；分数用 `diagonal-fractions`；小型大写字母标签用 `all-small-caps`；数据/代码区关连字 `font-variant-ligatures: none`，防 `fi`/`!=` 连写误读
12. 西文展示字体禁用清单（17 个 AI 生成界面默认脸）：Inter、Roboto、Open Sans、Noto Sans、Arimo、Lato、Source Sans、PT Sans、Nunito、Poppins、Outfit、Sora、Playfair Display、Bodoni Moda、Cinzel、Prata、Syne。用它们等于没选字体；需要西文展示体时选清单外且有性格的（如 Geist、DIN、Barlow，须随稿捆绑或确认渲染环境可用）
13. 字体配对规则：禁止双 sans（两个无衬线族配对无张力）；display 与 body 跨类配对（serif 展示 + sans 正文，或特重 sans 展示 + serif 正文）；每个场景只允许一个表现型字体；配对必须说得出一条张力理由（年代反差 / 软硬反差 / 宽度反差），说不出就退回单字族加减字重

## 5. 色彩纪律

1. 每页最多 1 个强调色（品牌主色之外）；强调色饱和度低于 80%
2. 禁止 AI 紫/蓝霓虹渐变作为默认审美；品牌色是紫色时除外，且须整套一致
3. 强调色一致性锁定：一旦选定，全套汇报所有页面使用同一个强调色角色，不允许某页突然冒出新的彩色 CTA 或彩色徽章
4. 灰阶一致性锁定：全套要么暖灰要么冷灰，不混用
5. 禁止纯黑 `#000000` 大面积背景和纯白文字直射；用近黑/近白
6. 阴影必须带背景色调（如深蓝底上用深蓝阴影），禁止纯黑硬阴影
7. 单页主题锁定：一页要么浅底要么深底，禁止半页反转
8. 页面配色与图表真源冲突时，以图表主色为准（见主文件图表真源冻结条款）

## 6. 布局纪律

1. 反居中偏好：内容页默认左对齐或不对称分区（如 7:5、8:4 分栏）；仅封面和单一结论页允许居中
2. 禁止"三个等大卡片横排"作为功能介绍的默认版式；用不对称 bento、2 栏交错或纵向节奏替代。例外：数据看板页的等大指标卡（KPI 数字卡）属于数据呈现而非功能营销，不受此限
3. Bento 格子数 = 内容条目数：3 条内容就 3 个格子，禁止出现空格子或凑数格子
4. 版式重复限制：同一版式家族（如"左图右文"）在一页内最多出现 1 次；多页连续使用时第 3 次必须换版式
5. 禁止"左大标题 + 右侧浮动小解释段落"的分栏头；标题和解释纵向堆叠
6. 元素不重叠、不溢出；绝对定位块之间保留明确间距
7. 留白是设计决策：区块间距按 `24/32/48px` 基线走，宁可空一点也不挤
8. 卡片只在层级真实需要时使用；能用留白和 `1px` 分隔线分组的，不用卡片
9. 每页最多两个视觉焦点：一个主焦点 + 一个次焦点；出现第三个竞争元素时降级或删除
10. Hero 文本块宽度取画布 60-80%，两侧留呼吸；满宽大字顶边显廉价
11. 页面深度最多三层（背景层 / 内容层 / 强调层），不叠更多层
12. 大元素锚定画布边缘或网格线，不无理由漂浮在留白中央
13. 强调色占可见面积 15-25%：低于下限找不到重点，高于上限不再是强调
14. 暗底禁止全屏线性渐变（大面积渐变产生色带 banding）；用径向光晕或实底
15. 中性灰向品牌色相倾斜 2-4%（暖灰/冷灰里带一点品牌 hue），不用纯中性灰，避免页面与品牌脱节

## 7. 形状与容器纪律

1. 形状一致性锁定：一套汇报选定一组圆角档位（如 `8/12/16/24px`），全套一致；禁止圆角混用
2. 需要高级感容器时用嵌套结构：外层壳（浅色底 + 细描边 + 内边距 + 大圆角）包内层芯（内容背景 + 小一档的同心圆角）
3. 徽章/标签用小圆角胶囊 + 小字号 + 宽字距，但每页最多 1-2 个，禁止贴满
4. 禁止给图片叠加标签胶囊（如 `图 · 02` 一类）；说明文字放图外下方

## 8. 内容真实性纪律（汇报场景强化）

1. 禁止伪造精确数字：`92%`、`4.1×`、`48k` 必须来自母稿真实数据；占位数据必须显式标注"示意"
2. 禁止 AI 文案套话："赋能"、"抓手"、"打通闭环"、"Next-Gen"、"Seamless"、"Unleash" 一类空洞动词，改用具体动词
3. 禁止占位名称：不出现 "某某项目"、"Acme"、"张三李四" 一类假名，用母稿真实名称或留空待补
4. 文案自查：交付前重读每页所有可见文字，凡语法不通、指代不明、读起来像 AI 硬凑的句子，全部重写
5. 一套汇报一个文案语域：不混用技术黑话和营销口号
6. 页面不残留表名、类名、Topic 名、API 路径、未解释缩写

## 9. AI 痕迹清单（禁止项）

以下模式是 LLM 生成界面的典型痕迹，默认全部禁止：

1. 眉标编号："01 / 概览"、"002 · 能力"、"SECTION 03" 一类编号眉标
2. 装饰性彩色状态点：列表项、导航、徽章前的彩色小圆点（除非表达真实状态）
3. 版本号页脚：`v1.4.2`、`Build 0048`、`last sync 4s ago` 一类
4. 滚动提示：`Scroll`、`↓ scroll`、滚动鼠标图标（幻灯片无滚动）
5. 中点分隔滥用：`·` 每行最多 1 个，禁止 `foo · bar · baz · qux` 串
6. 照片署名式装饰说明：`图 03 · 档案` 一类伪注记
7. 假产品截图：用 div 拼出的假仪表盘、假终端、假任务列表；需要展示产品时用真实截图或图表真源
8. 装饰文字条：封面底部的 `品牌. 动效. 空间.` 一类口号条
9. 每行 `border-top + border-bottom` 的长列表：改用分组 + 稀疏分隔，或卡片化
10. 破折号做装饰分隔：标签、眉标、按钮中禁止用 `—`/`–` 做分隔符；中文正文中的规范破折号用法不受此限

## 10. 完整输出纪律

1. 每页 HTML 必须是完整可运行文件，禁止 `<!-- 其余同上 -->`、`// ...`、"参考上一页" 一类占位
2. 要求 N 页就交付 N 页；因长度限制必须分段时，在完整页面边界处断开并明确标注续写位置
3. 交付前核对：页面数、图表引用数、token 变量完整性，三者缺一不可

## 11. 数据呈现纪律

1. 同一概念跨页/跨动画变化时保持同一视觉空间：同图表类型、同位置、同标尺，只换数值；禁止换图表类型重新表达同一指标
2. 关键数字给视觉重量：大字号 + `tabular-nums` + 强调色，至少占一样；禁止把核心数字埋在正文段落里
3. 禁止饼图：人眼比角度能力差，改条形图或点图
4. 禁止双轴图：暗示不存在的相关性；拆成两张图并排
5. 单页图表面板 ≤6 个；超过就拆页
6. 图表网格线删除或降到单色 hairline 一档，不与数据抢视觉重量
7. 单系列数据不用图例：直接在线尾/条端标注名称

## 12. 品味六维（高级感总判）

规则清单（§4-§11）解决"不出错"，品味六维解决"是否高级"。全部规则过完后用六维做一次总判；规则之间冲突时，回到六维裁决哪条优先；想破一条规则，先回答"破了它服务六维中哪一维"——答得上就破，答不上就不破。

| 维度 | 判据 |
|---|---|
| 重量感 | 标题、大数字、图表区的视觉重量与信息重要度匹配：页面上最重的元素就是最重要的信息。眯眼看页面，虚化后第一个跳出的元素应是主信息 |
| 礼让观众 | 给读者视线留反应空间：结论区独立、不被装饰包围，每页视觉焦点 ≤2 个（→ §6）。读者 30 秒扫描能读完结论，不被次级元素打断 |
| 留白 | 留白是主动设计决策不是剩余空间：留白占比达标（→ §13），区块间距落在 `24/32/48px` 基线（→ §6）。页面看起来不挤，视线有喘息点 |
| 克制 | 全页只有一处做到 120% 精致（唯一 signature 元素，→ `anti-ai-slop-design.md` Signature 元素节），其余保持 80% 恰到好处。指不出最精致的一处＝平庸；指出三处＝到处炫技，廉价 |
| 手感 | 对齐、间距、色温有一致工艺：同类元素间距值相同、字级梯度拉开而非机械等分、颜色使用成系统（→ §4、§5、§6） |
| 敬意内容 | 不用装饰充数、不藏数据来源（→ §8）：每个元素能回答"它服务什么信息"；删掉某装饰后信息不损失，就删掉它 |

六维不打分，只做过/不过二值判定。任一维不过，给出对应修复方向，走 `premium-review-fix.md` 三步流程。

## 13. 视觉密度条款（上限与下限）

密度错误是双向的：塞太满会拥挤，太空会显得没做完。两个方向都有硬判据。

下限（防空旷）：

1. 内容页不得只有一句大字浮在纯色底上——那是线框稿不是成品；每个内容页要有足量真实内容元素（数据、图表、对比项、引语出处）
2. 数据看板页每页 ≥3 处可近读的数据信息点（如数值＋单位＋对比基准/趋势），不是只放一个孤立大数字
3. 验收表述：任意一页与同套汇报中做得最完整的一页并排摆放，不显单薄

上限（防拥挤）：

1. 留白占页面总面积 ≥40%；极简基调页 ≥60%
2. 单页图表面板 ≤6 个（→ §11）；视觉焦点 ≤2 个（→ §6）
3. 每页正文只承载 1 个核心观点；支撑细节进演讲者备注或附录页，不堆上屏

密度分型（对应 §2 的 VISUAL_DENSITY 刻度取值）：

| 页面类型 | 密度档 |
|---|---|
| 封面 / 结论 / 引语页 | 克制型：低密度、大留白、单焦点 |
| 数据看板 / 架构 / 案例对比页 | 高密度型：网格填满，但仍受上限条款全部约束 |

减法是 fallback 不是普适律：高密度页需要密度支撑说服力时加法优先——加的是有内容的信息点，不是装饰性图标。

## 14. 3 米测试（自检项）

1. 判据：3 米外（会议室投屏典型距离）看页面，或把页面截图缩到手机屏大小——主信息（页面标题、核心结论、关键数字）仍可读
2. 读不出即字级梯度错误：回 §4 调字级层级，不靠加粗、变色、加描边补救
3. 与 §13 的分工：密度下限防空旷，3 米测试防高密度牺牲可读性，两者构成视觉密度的上下限
4. 每页交付前执行一次；不过的页回 §4 修字级后重测，不带入交付

## 15. 品位锚点（无品牌资产时的对齐参照物）

设计从已有上下文长出来：优先用品牌资产、图表真源、既有汇报页模板（→ §1 解读信号第 3 条）；其次用用户点名的参照物——要 URL 或截图，不凭记忆印象做；两者都没有时才用本节锚点，并向用户声明这是起点不是定稿。

| 维度 | 首选 | 避免 |
|---|---|---|
| 字体 | 中文默认栈＋一个有性格的西文展示体（§4 禁用清单之外选，随稿捆绑） | 全场系统默认字体无层级；命中 §4 禁用清单的西文展示体 |
| 色彩 | 一个有温度或冷峻的锚定底色＋单一强调色贯穿全套（→ §5） | 多色聚类，除非数据分类真有 ≥3 个维度 |
