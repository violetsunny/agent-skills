# 批量逐字稿生成 prompt 模板（Phase 4）

契约来源：`references/slide-layout-strategies.md`「话术（逐字稿）写作三铁律」。使用方式：让 AI 为整套 deck 批量生成逐字稿时直接使用下方 prompt；生成后仍按三铁律逐条验收。

```text
为每一张 slide 写一段 150-300 字的逐字稿，放进该页 `.notes` 容器。
要求：
1. 用口语，不用书面语（所以/但是/接下来，不是因此/然而/综上所述）
2. 核心关键词用 `<strong>` 加粗
3. 过渡句独立成段（每段 1-3 句）
4. 读起来像说话，不像念稿
5. 结尾自然过渡，引出下一页
6. 逐字稿只写进 `.notes`，页面可见区域零出现提示语与口播内容
```
