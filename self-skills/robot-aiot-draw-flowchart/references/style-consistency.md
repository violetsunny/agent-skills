# 统一样式规范

本文件是 draw.io XML 输出的唯一样式权威。`references/` 中的示例若与这里冲突，以本文件为准。

## 节点样式标准

| 属性 | 标准值 | 说明 |
|------|--------|------|
| fontSize | 12 | 所有普通节点统一 |
| strokeWidth | 2 | 所有普通节点统一 |
| arcSize | 15 | 圆角半径统一 |
| shadow | 0 | 常规节点不使用阴影 |
| fillColor | #FFFFFF | 常规节点白色填充 |

## 分层容器样式标准

| 属性 | 标准值 | 说明 |
|------|--------|------|
| strokeWidth | 3 | 分层容器统一 |
| 层标签 fontSize | 16 | 层标签统一 |
| 层标签 fontColor | 层边框色 | 与层色对齐 |
| 蓝色层 fillColor | #E8F4FD | 不使用 `#E3F2FD` |
| 主椭圆 strokeWidth | 3 | 核心椭圆强调但不再放大到 4 |

## 箭头样式标准

| 属性 | 标准值 | 说明 |
|------|--------|------|
| strokeWidth | 3 | 所有箭头统一 |
| dashed 语义 | 仅反馈/循环/隔离断联 | 隔离/断联/边界切断类目可用虚线；演进、推进、错误路径一律实线 |
| 箭头颜色双源裁决 | 类型/层级规则优先 | 同一箭头同时命中通用语义色与图表类型/层级配色规则（如分层图跨层箭头用目标层主题色）时，类型/层级规则优先 |

## 文本与内嵌样式标准

| 属性 | 标准值 | 说明 |
|------|--------|------|
| 内嵌 HTML font-size | 11px | 节点内富文本统一 |
| 副标题位置 | x=450, w=900 | 1800px 画布下居中 |

## 颜色使用标准

1. 只允许使用 `references/color-schemes.md` 色板内颜色
2. 警告黄色系固定为背景 `#FFF8E1`、边框/主色 `#FFA000`
3. 蓝色层背景固定为 `#E8F4FD`
4. 中性工具色豁免：`#CCCCCC` 一类中性工具色仅限分隔线、占位边框、禁用态等非数据元素，是色板规则的明确豁免，不与"数据系列禁灰"冲突；数据系列仍禁止用灰色

## 语义例外

| 元素 | 偏离项 | 原因 |
|------|--------|------|
| 语义强调节点 | 特殊背景色 + strokeWidth=3 | 需要视觉突出 |
| 总结条/摘要条 | fontSize=14 | 需要层级区分 |
| 主椭圆等核心视觉元素 | fillColor=层色 + shadow=1 + strokeWidth=3 | 保留焦点强调 |

判断原则：任何偏离标准的样式都必须有明确语义理由。
