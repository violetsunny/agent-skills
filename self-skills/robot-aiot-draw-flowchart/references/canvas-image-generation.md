# 画布级图片生成能力（内化自 canvas-design）

## 定位

当流程图/架构图需要以高质量图片形式嵌入文档、汇报或网页时，使用本规则生成博物馆级视觉输出。区别于普通 PNG 导出（`png-export.md`），本能力强调设计哲学驱动的视觉表达。

## 适用场景

1. 流程图需要作为独立插图嵌入技术文档或白皮书
2. 架构图需要高精度印刷级输出（300DPI+）
3. 需要将图表转化为具有设计感的视觉作品（封面、Banner、社交媒体配图）
4. 普通 PNG 导出无法满足视觉品质要求时

## 两步工作流

### Step 1: 创建设计哲学

在生成图片前，先输出一段设计哲学文档（4-6段），包含：

1. **命名运动** — 给本次视觉风格一个名字（如"工业精密主义""数据极简派"）
2. **视觉宣言** — 描述核心视觉原则（如"信息通过空间密度而非文字传达"）
3. **色彩策略** — 主色、辅色、背景色的选择理由，与图表语义的关联
4. **排版原则** — 字体角色分工、字号层级、留白节奏
5. **工艺标准** — 明确"精致度"的具体衡量标准

### Step 2: 画布表达

基于设计哲学生成 .png/.pdf 输出：

- **90% 视觉 / 10% 文字**：信息通过空间、形式、色彩、构图传达，文字仅作视觉点缀
- **微妙引用原则**：主题作为隐性概念 DNA 嵌入形式/色彩/构图中，不直白展示
- **边界约束**：所有元素必须在画布内，不重叠、不溢出，有呼吸空间
- **精炼优于添加**：第二轮优化不增加图形，而是让已有构图更凝聚

## 与普通 PNG 导出的区别

| 维度 | 普通 PNG 导出 | 画布级图片生成 |
|------|-------------|--------------|
| 目的 | 技术文档内嵌 | 高品质视觉作品 |
| 流程 | SVG → cairosvg/Puppeteer | 设计哲学 → 画布渲染 |
| 文字比 | 保留原始标注 | 90%视觉/10%文字 |
| 适用 | 日常图表交付 | 封面/Banner/印刷/社交配图 |

## 约束

1. 不得改变原始图表的数据语义和结构关系
2. 设计哲学必须与图表内容匹配，不能为美观牺牲准确性
3. 输出分辨率 ≥ 2K（长边 ≥ 2048px），印刷场景 ≥ 300DPI
4. 多页输出沿同一哲学但各有独特变化，不做简单复制
