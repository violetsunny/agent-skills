# Longterm Playbook（长线持仓管理框架）

## 适用场景

用户提出加仓、止盈目标、摊薄成本、持仓核验、季度基本面跟踪、长期持有决策时使用。本框架面向持有期 3-5 年的长线策略，与 `screening-playbook.md`（短线筛选）口径互斥——同一份报告不得同时出现"止损线"与"长期持有"类矛盾建议，长线仓禁止输出止损/减仓建议。

## 用户策略画像（默认值，用户明示可覆盖）

| 项 | 默认值 |
|---|---|
| 本金规模 | 20-50 万 |
| 持有周期 | 3-5 年 |
| 止盈目标 | 盈利 25%-30% 卖出，不吃最后一口 |
| 选股范围 | 只看行业龙头，不看小票 |
| 行业偏好 | 大科技 + 高股息 |
| 下跌应对 | 不因下跌卖出，逢低分批加仓摊薄成本 |
| 操作频率 | 拒绝频繁短线，按季度财报节奏验证 |

上表为 skill 内策略数字的**单一权威源**：其他文档（SKILL.md/AGENTS.md）只引用本表，不复述数字。画像变更以用户最新表述为准，先更新本表再同步 memory。本 playbook 只承载方法论，不写入具体持仓数据（持仓在 `portfolio` 本地 JSON 与 memory 中）。

## 一、分批加仓法

### 档位设计

1. 参考位：用 120 日/250 日前低、多次假破收回的前低带、整数关口作档位锚点；`quote-history`（前复权）计算各窗口前低与摆动低点。
2. 三档结构：第一档（技术支撑带）/ 第二档（支撑失守后下一带）/ 第三档（极端恐慌假设位）。第三档子弹留给市场级恐慌日（如宽度 500:6000 级别），不一次性打完。
3. 股数约束：A 股必须 100 股整数倍，每档最低 100 股，禁止 50/70 股等零股。
4. 触发纪律：触发区间到了按表执行，没到不动；加仓日不预测大盘，杜绝"感觉要涨了提前买"。

### 摊薄成本测算

- 新成本 = (原股数 × 原成本 + 加仓股数 × 加仓价) / 总股数
- 报告必须给出加仓前后"回本价降幅"与"止盈所需涨幅"对照，体现摊薄价值。

### 集中度检查

- 加仓前计算产业链集中度（同一行业持仓市值合计 / 总市值）。>70% 时显式提示：行业级利空将同时打击多只持仓，分散失效。
- 缓冲手段：放弃基本面较弱标的的第三档、弹药向基本面最优持仓倾斜、用防御性挂单引入分散。

### 与 market-regime 联动

- `distribution-days` 输出 CAUTION（action=AVOID_NEW_ADDS）或更差档位时，抄底加仓建议必须显式对抗该约束并说明理由（估值+基本面），或暂停新增。长线框架不豁免 regime 警示，对抗必须显式陈述，不得静默忽略。

## 二、止盈框架（盈利 25%-30% 卖出）

### 目标价测算

- 卖出区 = 摊薄后成本 × 1.25 ~ 摊薄后成本 × 1.30。
- 三口径对照：不加仓（现有成本）/ 仅第一档加仓后 / 全部档位执行后，各口径给出"现价需涨幅"。

### 卖出执行

- 进入卖出区后分 2-3 批卖出（每批 100 股整数倍），不追求卖在最高点。
- `watchlist --target` 设卖出区上沿作价格告警；`portfolio show` 核对实时盈利率。

### 卖出只有两个理由

1. 达到止盈目标（盈利 25%-30%）。
2. 基本面恶化（见季度验证清单），此时"恶化卖出"优先于止盈目标。

价格下跌本身不是卖出理由，禁止输出止损/减仓建议。

## 三、季度基本面验证清单

每年 1/4/7/10 月财报季（披露窗口 1 月、4 月底、7 月、10 月底）核对一次，恶化信号映射到 CLI 字段：

| 持仓类型 | 验证指标 | 数据源 | 恶化信号示例 |
|---|---|---|---|
| 周期科技（存储/半导体等） | 毛利率、ROE、行业现货价趋势 | `fundamental` + `news` | 现货价趋势性下跌 + 毛利率连续两季下滑 |
| 制造/工控 | 营收增速、市占率、出海进展 | `fundamental` + `announcement` | 份额被侵蚀 + 连续两季净利下滑 |
| 高股息 | DPS、派息率、分红连续性 | `dividends` | 安全评分降档 + 派息率异常 |
| 全部 | 大客户订单、产能利用率 | `announcement` + `irm-qa` | 大客户订单流失/转移 |

- 任一恶化信号触发：对应持仓加仓档位作废，重评持有逻辑。
- 无恶化：不看盘不操作，继续按表持有。

## 四、龙头核验标准

新仓/加仓前核验龙头属性，至少满足其一：

1. 细分市场份额全球或国内前三（来源：年报/研报口径，`news`/`announcement` 交叉验证）。
2. 产业链核心供应商地位（如某芯片巨头的最大封测供应商）。
3. 行业定价权或标准制定角色。

小票、题材股、跟风股一律不进入长线加仓框架（短线观察走 `screening-playbook.md`，但不给加仓建议）。

## 五、高股息筛选标准

1. `dividends` 安全评分 ≥60（good 及以上）。
2. 股息率 ≥3%（分母用实时价）。
3. 派息率 30%-70%（过低无诚意，过高不可持续）。
4. 连续分红增长年数 ≥3。
5. 挂单纪律：高股息仓用限价挂单等回调，不追高；挂单与加仓现金共用同一资金池，先成交先扣。

## 六、右侧确认信号（停止加仓、转为持有的条件）

| 信号 | 数据源 | 阈值参考 |
|---|---|---|
| 主力资金流 | `money-flow --scope market` | 连续 ≥3 日转正（单日衰竭信号仅作预警） |
| 赚钱效应 | `limit-sentiment` | >55% |
| 炸板率 | `limit-sentiment` | <30% |
| 关键价格位 | `quote-realtime` | 收复破位点/前低 |
| 行业现货价 | `news` | 环比转涨 |

全部满足 = 右侧确认，此后不再逢低加仓（价格已脱离低位区），转为持有 + 季度验证。

## 七、长线分析输出模板

报告默认落盘 `.analysis/YYYY-MM-DD-主题.md`，结构：

1. 结论速览（资金需求 / 触发优先级 / 止盈目标价 / 最大风险）
2. 持仓现状表（股数/成本/现价/浮动盈亏/市值，附时间戳）
3. 持有逻辑核验（基本面指标表 + 3-5 年逻辑）
4. 分批加仓档位表（触发区间/技术依据/股数/摊薄成本/回本价降幅）
5. 止盈目标价表（三口径对照）
6. 集中度风险提示
7. 长线纪律（卖出理由/验证节奏/触发纪律）
8. 右侧确认信号
9. 最近验证点（距下一财报季天数）
10. 数据口径与降级说明

表达纪律：股票名用全名+代码；结论分层（事实/信号/判断/风险）；不给收益承诺；深度报告交付前经 `cross-check-reviewer` 复查。

## 八、六种选股策略路径（方法论总纲，用户 2026-10-19 确认采纳）

普通人可行的六条路，每条都能走通；关键不是知道，而是选一条适合自己的坚持走下去。

| # | 路径 | 核心做法 | 收益预期 | 能力要求 |
|---|---|---|---|---|
| 1 | 等大跌买指数 | 平时不动，只用闲钱；"股灾式"大跌时买宽基ETF，不选股 | 一次行情 30%-40% | 极低，靠耐心 |
| 2 | 一两只股票反复波段 | 永远保留现金，涨卖一点跌买一点，把成本一路做低甚至做负 | 摊薄成本 | 中，需纪律 |
| 3 | 攒股收股息 | 股息率约 5% 的国企央企，跌透时买入吃分红 | 分红 + 可能股价翻倍 | 低，靠选股常识 |
| 4 | 看懂周期反向布局 | 远离炒上天的板块，找没人关注的低估板块（如 2022 布局银行股） | 周期回归翻倍级 | 中高，需逆向定力 |
| 5 | 价值投资等好公司打折 | "数月亮不数星星"只买龙头，市场情绪打到极度便宜时分批重仓，等价值回归 | 2-3 倍甚至更多 | 高，需估值判断 |
| 6 | 赚企业成长的钱 | "数星星"，投市值小但前景优秀的公司 | 数倍至数十倍 | 极高，需行业深刻理解 |

**与用户现行策略的映射**：

- 主路径 = **第 5 种**（只买龙头 + 极度便宜时分批买入 + 等价值回归）：兆易创新603986 / 通富微电002156 / 汇川技术300124 的三档逢低加仓框架即此路径的执行；紫金矿业601899（全球有色龙头，实测股息率仅 1.41%，2026-10-19）不属第 3 种，其挂单 28.6 等回调的防御仓按本路径龙头打折逻辑管理
- 辅路径 = **第 3 种**（攒股收股息）：长江电力600900（实测股息率 3.38%、连续分红 23 年，达第五节 ≥3% 标准但低于原文 5% 理想值；派息率 70.9% 略超上限、连续增长 2 年略欠，2026-10-19）挂单 27.8 即此路径
- 第 2 种（波段做低成本）与用户"长线仓不减仓"纪律冲突，仅可用于止盈后的余仓，不作主策略
- 第 1/4/6 种暂不采用：第 1 种与主辅路径资金冲突；第 4 种需逆向择时能力；第 6 种与"只看龙头不看小票"原则相悖

分析输出时若涉及策略选择，以主路径（第 5 种）+ 辅路径（第 3 种）为默认框架，不主动推荐其他路径。
