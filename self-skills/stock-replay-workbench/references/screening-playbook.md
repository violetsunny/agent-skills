# Screening Playbook

## 适用场景

用户要找短线股、强势股、明日观察池、情绪票候选时使用。

## 基础框架

这套框架致力于建立一个可解释的筛选工作流。

### 硬条件

| 条件 | 默认值 | 理由 |
|---|---|---|
| 非 ST / 非退市 | 必须 | 排除风险壳和异常票 |
| 流通市值 | `<= 150 亿` | 保留弹性 |
| 近 20 交易日有涨停 | 必须 | 保留短线活跃度 |
| 交易所范围 | 主板 / 深证 / 创业板 / 科创板 | 聚焦 A 股主流短线池 |
| 换手率 | `<= 10%` 为默认上限 | 避免纯情绪透支 |

### 加分项

1. 近 3 日主力净流入为正。
2. 所属题材是当天主线或前排分支。
3. 量价关系健康：放量突破或缩量回踩，而不是高位爆量滞涨。
4. 近 20 日涨停次数更高。
5. 龙虎榜、封单、行业强度能相互验证。

### 减分项

1. 高位连续加速后放巨量。
2. 板块退潮、核心龙头走弱。
3. 公告或新闻存在明显利空。
4. 资金流与价格表现背离。

## 实操步骤

1. 先调用基础的榜单排行、涨跌停池、行业表现等数据。
2. 用硬条件做第一轮过滤。
3. 对候选股补充资金流、公告、龙虎榜等二次确认信息。
4. 按加分项和减分项重新排序。
5. 输出时不要只给名单，要给入选理由、风险和观察条件。

## 推荐输出字段

| 字段 | 说明 |
|---|---|
| 代码 / 名称 | 基础标识 |
| 涨停次数(近 20 日) | 活跃度 |
| 流通市值 | 弹性过滤 |
| 最新价 / 涨跌幅 | 当前状态 |
| 换手率 / 量比 | 情绪强度 |
| 主力资金 | 资金确认 |
| 所属行业 / 概念 | 主线归因 |
| 入选原因 | 1-2 句说明 |
| 风险点 | 1-2 句说明 |

## 表达口径

不要说 `明天必涨`、`确定能连板`。

应该说：

- `适合列入明日观察池`
- `具备情绪延续条件，但需看竞价和量能确认`
- `更像板块跟风，不宜按龙头预期处理`

## 查询契约提醒

1. 不要对全市场逐股深挖所有二次字段。
2. 先缩池，再逐个补充。
3. 资金流、龙虎榜、公告应作为确认项，而不是孤立打分项。
